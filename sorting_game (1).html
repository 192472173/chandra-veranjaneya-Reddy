Bubble Sort
Compare adjacent elements and swap. The largest "bubbles" to the top each pass.
O(n²) O(1) Stable
🎯
Selection Sort
Find the minimum in each pass and place it at the front of the unsorted portion.
O(n²) O(1) Unstable
🃏
Insertion Sort
Build sorted array one item at a time, inserting each in its correct position.
O(n²) O(1) Stable
⚡
Quick Sort
Pick a pivot, partition, and recursively sort. Divide and conquer at its best.
O(n log n) O(log n) Unstable
🔀
Merge Sort
Divide array in half, sort each, then merge. Guaranteed O(n log n) always.
O(n log n) O(n) Stable
